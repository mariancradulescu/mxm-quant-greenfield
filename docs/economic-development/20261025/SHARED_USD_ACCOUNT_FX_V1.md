## Actual account integration

UseSharedUsdConversion is a separate opt-in model mode in the EXISTING MxmPortfolioAccountReplay, not a second engine/account. Its whitelist currently covers the authenticated EURUSD/GBPUSD USD-quote identities only; other instrument mappings need explicit support. Default false preserves existing replay arithmetic and all closed reference configurations. The actual Robot project/strategy/authority/risk parameters are not changed or activated.

A typed MxmUsdEurMark contains actual source observation/side timestamps and EURUSD BID/ASK. Validate source symbol, UTC geometry, both side ages<=5000ms, uncrossed positive prices, monotone observation/side clocks and no changed price at an identical side timestamp. Conversion-only events update gain/loss factors for cached USD quotes, then the same account's equity/drawdown/risk evaluation. They do NOT change instrument quote clocks, consume an intent, touch a price-based stop, charge a fee, change cash/used margin or open/close a position. A modeled equity/margin halt can still follow revaluation; it is not broker stop-out or forced liquidation.

A new executable instrument quote requires conversion observations STRICTLY earlier than its timestamp, fresh on both sides, and explicit matching gain=1/ASK and loss=1/BID factors. GBPUSD's own price cannot convert USD PnL to EUR. Explicit captured EURUSD commission scenarios use the same admitted conversion BID rather than a new quote's unproven same-ms conversion. The existing GBP captured-fee prohibition remains; no historical GBP fee/margin or minimum-volume certification is fabricated.

The typed paired-source adapter maps GBP_QUOTE_GROUP to an instrument quote only after independently validating its raw values/clocks, and FX_VALUATION_ONLY to a conversion mark. It requires explicit units/margin/commission/slippage/stop assumptions, with no defaults interpreted as broker evidence. Invalid currency data invalidate conversion globally; an invalid GBP quote remains an instrument-specific event. An open exposure through either required unpriceable source faults the model, suppressing a favourable report or checkpoint. While flat, invalid observations revoke affected current-bucket intents; subsequent orders still need a genuinely new admitted decision/quote path. Nothing is silently filled, interpolated or reset to EUR200.
