# Native executable data qualification V1

Decision: DATA_LIMITED. This is a closed data qualification, not a directional alpha experiment. It neither establishes profitability nor falsifies a trading mechanism.

The policy was committed before numeric qualification. It fixes EURUSD/1, GBPUSD/2 and SpotCrude/250, the original four DEVELOPMENT blocks and complete ISO UTC weeks W35–W37, Monday–Friday entry clocks 09:15 and 13:15, and one-hour/four-hour horizons. No clock, threshold or rule was changed after results.

Accepted C031 and Stage A V6 members were recovered byte-for-byte, with archive/member/acceptance SHA256 bindings. Numbered base64 files contain only the unchanged owner RSA/OAEP/OpenPGP ciphertext. PRIMARY145, PW02, frontier captures, earlier native warehouses and DEMO tick archives were inspected. DEMO ticks are not substitutes for the account-fingerprint-bound LIVE cohort. Stage A friction summaries do not transfer raw ticks. Absence from MASTER1576 is not absence at the broker.

The unchanged VIEW/account authentication and accepted raw-envelope M5 decoder completed only the missing September 14–16 tail and fixed BID/ASK boundaries. Native M5 responses returned count-limited bars backwards from the end timestamp beyond the requested lower bound. The thin adapter preserves raw envelopes, validates the same account/period and OHLC invariants using the existing decoder, discards lower overfetch, and proves the lower bound was exhausted. Upper-bound overfetch is rejected. Original hasMore=true is retained; the full older history is not claimed downloaded. Tick requests preserve bounds, encoded pages, timestamps, age and roundtrip latency. Capture latency is not actual historical bar delivery latency.

The M5 prerequisite is satisfied at every frozen entry. Qualification fails the frozen timestamp and preliminary economic gates. A last observed side-tick timestamp is not a certified executable snapshot timestamp. This caveat does not reopen V1 or relax its limits. Shared EURUSD conversion creates dependence between instruments. The pre-entry range at minimum volume is a scale/risk proxy, not a stop-loss, drawdown or survival certificate. Current fees, margin, swap and conversion are explicit scenarios, not dated historical contracts. Unknown expenses are not set to zero.

Receipt readback reads saved causes and raw-response metadata without rerunning qualification, signals, labels, returns or PnL. FINAL_DELIVERY_RECEIPT_V1.json records every source commit, run/job, encrypted release/asset SHA256, session envelope SHA256 and adapter failure. All accepted prior files remain intact. Legacy automatic publication-state workflows fail on a missing old state field already absent at the accepted base; that state and its frozen validator were preserved.

The next evidence task is to validate native side-tick/quote-state and causal FX semantics from saved raw pages and official references before a separate prospective decision/abstention design. Do not salvage this closed qualification by changing thresholds, choose instruments on observed returns, or reacquire available data. Dated expenses, slippage/fills and actual historical bar delivery remain uncertified.

The final robot remains one autonomous C#/.NET cTrader Cloud cBot. Bars, Tick and Symbol properties document the native data categories. Open API, Python and GitHub are offline research tools only. The approved DeliveryProbe package is unchanged. No orders, protected forward, authentication changes, extra Cloud probes/deployments or directional experiment occurred.
