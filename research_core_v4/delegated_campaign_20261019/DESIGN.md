A separate, non-App workflow computes a distinct evidence-granularity analysis. Its token has contents:read only; it receives no App key or writer route. It publishes encrypted output and public receipt, not economic plaintext. Its immutable execution marker prevents later documentation pushes from replaying this analysis.

Normal runtime continues after ordinary token and lease turnover using fresh workflow identities, Git checkpoints and fresh scoped/revoked App tokens. The keyless scheduler has no bootstrap or migration command. A recovery drill may disable only one run's immediate automatic handoff; the periodic/independent dispatcher must then recover ordinary continuation from protected Git. This does not grant authority to replay an unresolved intent. Any pending intent or unknown ACK stops for investigation rather than executing it again. Native configuration changes, decryption mismatch, revocation or terminal research state also stop.

The registered queue is finite and safely stops if complete causal, historical cost, execution-risk and confirmation evidence is absent. This is not a claim that all economic hypotheses or all authorized datasets are exhausted. New justified scientific definitions require an append-only versioned successor with exact predecessor admission under the same delegation; no personal OWNER technical review or new bootstrap is required. The operational App is not allowed to rewrite its own source or administrative admission. Exceptional source installation remains an administrative Director operation.
