# Delegated operational ownership — versioned B–C successor

Authority is the OWNER's explicit development delegation installed through native GitHub administration: an immutable source ref, an exclusive environment credential route, the existing pinned App/installation and the exact active-ref grant. No source or manifest from the personal-review architecture is rewritten or reinterpreted. No personal OWNER review is asserted, signed or posted.

Admission checks authenticated source ref/SHA, its exact active creation/update/deletion/non-fast-forward seal without bypass, the exact App-only active-ref ACL, independent append-only controls and the immutable OWNER1807 root. The old unapproved run must be natively CANCELLED with an empty review history. The environment transition replaces the old branch with one new sealed branch; it does not add a second key consumer. No new App, account, key, custodian, provider or service is introduced. Native administration remains a revocation/control root: this is not protection against the legal OWNER intentionally reconfiguring GitHub.

The same isolated issuer mints a scoped App token in every finite run and revokes it before emitting a success receipt. Native receive-pack CAS commits state.json and the existing-OWNER-key encrypted checkpoint in one Git tree. Each task requires a fresh run and fresh deterministic lease. A stale parent is exercised against native Git, not a local mutex. Pending work cannot be reexecuted or renewed after crash/unknown ACK. Cold recovery decrypts and verifies every saved result-to-intent binding before claiming new work. No scientific value, count, instrument or vector enters the public state.

Automatic handoff dispatches the next finite run after lease expiry. A keyless default-branch periodic dispatcher recovers a missed handoff using the durable Git checkpoint; it has no bootstrap route, App key or OWNER key. It refuses pending, revoked, completed or foreign-source state and suppresses dispatch while an existing runtime is active. No Actions artifact needs to remain available for continuation. Platform scheduling outages can delay execution; they do not authorize another bootstrap or guessing a checkpoint.

The fixed queue contains two independent cold OWNER1807 restorations, a NEW partial-identification analysis of the authenticated saved economic summary, and economic admission. The original price/feature/portfolio experiment is not repeated. Missing exits are not imputed to zero; partial baseline increments do not become full increments; no confidence interval is manufactured from adaptively exposed aggregates. Private results are encrypted. The final registered task ends safely without qualifying a cBot when complete causal/cost/risk/confirmation evidence is absent. Completing this finite queue does NOT exhaust all authorized research or establish permanent alpha discovery. Further scientific work needs versioned task definitions within the same delegation, rather than personal technical reviews by OWNER.

Native environment administration controls the descriptor and its revocation; the contents-only App cannot rewrite it.
