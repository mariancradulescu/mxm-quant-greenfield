# Controlled scientific laboratory V6

A finite declarative scientific driver reuses the accepted encrypted corpus and existing account/commission/FX/replay modules. No pilot/V4/V5 calculation is repeated. It admits two distinct pre-registered economic feasibility investigations: temporal authority for carry cashflows, then capital-scale access imposed by native minimum-ticket discreteness. The first **computed verdict** selects the second task through an explicit registry map. A supported-reference verdict instead stops; an unknown verdict, wrong source, exhausted budget, duplicate, pending state or ambiguous acknowledgement stops. No runner invents new hypotheses.

Each investigation has a fresh workflow, runner and token. The second reads and decrypts the **first result from durable Git**, verifies its source/design/parent/run and native successful jobs, and verifies that its task is the registered scientific successor. No Work state is carried. A separate keyless ordinary documentation job archives the OWNER-encrypted result and public research state in one linear Git commit, under existing append-only protection. It has no OWNER or App key. This is documentation/evidence publication, not privileged authority: active-v1 remains native App-only and unchanged. The worker has GET-only contents/read access and no App key. The keyless dispatcher needs only actions/write and contents/read. No new source seals or administrative grants are installed.

Source is fixed by exact commit and branch check with the existing append-only rule, as accepted for V5r1. This is not claimed to be a native branch-update prohibition. Ordinary documentation token permissions are reported separately; they are not called read-only and never presented as App authority.

The shared candidate gate refuses outcome trials when global attempt accounting is unresolved. Old 84/21 snapshots and heterogeneous V4 ledgers remain immutable evidence, not an invented current count. This finite program consumes two explicitly budgeted feasibility investigations and **zero new directional strategy identities**. Current catalogue terms cannot be used as historical terms. Carry is unidentifiable on a current snapshot; capital access with actual quotes and current cost scenarios is not alpha. Dates, prices, counts, margins and costs stay encrypted. Public output is limited to schema, source/task/hash/native identities, verdict, next task and safety flags.

The existing continuous account replay is integrated behind evidence/budget gates; its cross-week EUR200 continuity is tested using a labelled synthetic fixture. No unsupported strategy is sent through it, and its test profit is never economic evidence. Scientific qualification, confirmed portfolio allocation, ruin, HARD21, C# parity and the complete demo week remain conditional on a supported candidate. The new path demonstrates limited registered scientific continuation; it does not claim unlimited autonomous generation or recovery after every crash.

A failed stage has no automatic retry. Native run identity prevents replay; a durable completed checkpoint permits only a different registered successor. Ambiguous archive/dispatch stops. A controlled change of process between runners is not called an injected production crash. Historical BC/C CAS/revocation/recovery proofs remain accepted and are not rerun.
