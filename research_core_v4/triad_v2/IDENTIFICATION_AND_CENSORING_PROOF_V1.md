# V2 identification and limitations

At each cohort/clock, let X be the current three-column own-leg/calendar span, D the target-balanced causal relational predictor, Q=I-X X^+ and R=QD. X,D are observed before any evaluation Y. The current predictor nuisance mhat=XX^+D is fitted without outcome labels. With scalar a=sqrt(mean R²)>0, score psi=Rᵀ(Y-ghat)/(n a). Every chronologically fitted ghat at the same clock is a vector X b, hence Rᵀghat=0 pathwise for ANY estimated b. Under E[Y|currentX,D,past,retention]=X beta, Epsi=0 even if beta, D-X covariance and their distributions jump/drift together. Under E[Y|...]=X beta+theta D, Epsi=theta a and FWL coefficient Rᵀ(Y-ghat)/(RᵀR)=theta in conditional expectation.

This is partial-linear incremental information relative to a common within-cohort/clock intercept and own5/60minute control slopes. It does not prove nonparametric conditional independence, causal effects or invariance to arbitrary omitted nonlinear/identity-specific baselines. Target-specific fixed effects at one row per target would saturate the clock and destroy all information; that stronger null is deliberately NOT claimed. This limitation must survive governance and economic interpretation.

There is no random-time CV. g training uses only labels whose horizon has matured PLUS240minutes before a daily00:00update, from preceding90days. Actual Y is forbidden in this task. Unknown g values can be varied synthetically: their estimation error cancels exactly, rather than being treated as oracle. Random current m projections are recomputed in every synthetic geometry trial; stochastic inference remains uncertified until full exactgeometry tests pass.

No clipping follows Q; clipping a residual would destroy orthogonality. Clip rawD only before Q, normalize R by one common scalar only. Causal row membership is fixed BEFORE outcomes. Removing missing outcome rows later need not preserve RᵀX=0. Therefore if ANY causal row lacks its full future timestamp path, discard the entire cohort/clock/horizon; never refit Q on future-selected rows or impute missing Y. Conditional-mean-ignorable availability is a declared null assumption, not a guarantee for endogenous broker gaps. This stricter support has to be measured and can block V2 even where V1 majority support passed.
