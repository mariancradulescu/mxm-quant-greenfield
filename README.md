# MXM Quant Greenfield V2

Clean-room quantitative research program targeting Pepperstone Razor / cTrader / cTrader Cloud.

## Binding objective
Discover the strongest legitimately demonstrated, broker-executable, EUR200-capable system that maximizes realizable weekly and monthly final equity while maintaining positive net edge, causality, broker/capital realism, robustness, survival, cTrader Cloud portability, and at least 21 actually executed entries in every certified UTC ISO competition week.

## Clean-room boundary
The legacy repository `mariancradulescu/mxm-quant-director` is READ-ONLY evidence only. V2 does not inherit legacy algorithms, signal architecture, experts, allocators, exits, thresholds, governance stacks, or candidate numbering. V2 candidates begin at `V2-C001`.

## Research architecture
- Shared deterministic economic core.
- Cheap, broad, causal Discovery factory.
- Exact incremental causal Certification replay.
- Historical replay and cTrader live adapters may differ mechanically only, never economically.
- Continuous capital from EUR200; no weekly/monthly reset.
- Cashflows tracked separately from strategy performance.
- No live orders and no competition start without explicit user authorization.

Authoritative controls are intentionally minimal: `TRUTH_CAPSULE_V1.json`, `RESEARCH_CONTRACT_V2.md`, `CURRENT_STATE.json`, `data/DATA_MANIFEST.json`, and append-only `discovery/ledger.jsonl`.
